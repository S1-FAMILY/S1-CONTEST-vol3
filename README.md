# S1 CONTEST — Frozen edition

Ледяная тема сайта: ночной фон, падающий снег (canvas), ледяная рамка из ролика с параллаксом и бликами,
стеклянные карточки со снежными шапками и сосульками, сугробы, анимированный логотип.

## Структура
- `index.html` — разметка (контент не менялся; добавлены фон-слои и новый hero)
- `styles.css` — весь дизайн (цвета в `:root`)
- `script.js` — снегопад, параллакс, появление блоков, меню
- `img/` — ледяная рамка (`ice-wide.jpg` / `ice-tall.jpg`) и фото мастеров в ледяной тонировке
- `fonts/` — Cormorant Garamond и Manrope (локально, без Google Fonts)
- PDF-файлы без изменений

## Что где менять
- Дата в hero: блок `.hero-date` / `.hero-month` в `index.html`
- Плотность снега: `area`, `max` в `script.js` (объекты `back` и `front`)
- Яркость льда: `--iceO` и фильтры в `styles.css`
- При `prefers-reduced-motion` анимации отключаются автоматически
